### The part most providers skip

Most firms test **either** the application **or** the cloud account. We do both in one
engagement, so escalation chains that cross the boundary are actually findable:

```
file upload → writes to a bucket → bucket readable by a role
            → role reads production secrets
```

Each step can look acceptable in isolation. The chain is the finding.
